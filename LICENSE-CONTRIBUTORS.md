## 1. Permissão para quem quer contribuir

O Titular concede a qualquer pessoa uma permissão adicional, limitada e revogável, de:

- copiar e **modificar** o código **somente** para preparar uma contribuição ao projeto
  (corrigir um erro, propor um recurso, escrever testes ou documentação);
- **enviar** essa modificação ao Titular, como pull request ao repositório oficial
  (`github.com/Jeffinp/Kitsune`) ou por outro canal que o Titular indicar.

Essa permissão **não** inclui: publicar a modificação em outro lugar como projeto ou fork
independente, distribuir o código, usá-lo em outro sistema, produto ou serviço, nem qualquer uso
comercial. Um fork no GitHub existe apenas para abrir o pull request.

## 2. O que acontece com a sua contribuição

Ao enviar uma contribuição (código, testes, documentação, arte, tradução) você declara e aceita
que:

1. **A obra é sua** (ou você tem o direito de enviá-la) e não viola direitos de terceiros. Se ela

2. **Cessão ao Titular.** Você cede ao Titular, de forma irrevogável, mundial e gratuita, os

   contribuição e obras derivadas, em qualquer licença (inclusive proprietária ou comercial).
3. **Direitos morais** continuam seus onde a lei brasileira os garante. Você será creditado no
   histórico do git e pode ser citado nos agradecimentos.
4. **Sem remuneração** pela contribuição, salvo acordo escrito com o Titular.
5. A contribuição é fornecida **como está**, sem garantias.

Para registrar o aceite, todo commit deve levar a linha `Signed-off-by: Nome <email>`
(`git commit -s`). Isso equivale a dizer "li e aceito os termos de LICENSE-CONTRIBUTORS.md".

Quer usar o Kitsune num produto, vender, distribuir uma versão própria ou criar um sistema
derivado? Isso exige uma **licença comercial escrita** do Titular. Fale pelo contato em
[SECURITY.md](SECURITY.md) ou abra uma issue pedindo contato.
